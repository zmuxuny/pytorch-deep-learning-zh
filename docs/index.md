包含。PyTorch 2.0 是对旧版本的增量升级。

## 关于这门课

### 这门课适合谁？

**你：** 是机器学习、深度学习或 AI 方向初学者，想学习 PyTorch。

**这门课：** 用“代码优先、动手实践”的方式带你掌握 PyTorch 及大量 ML/DL/AI 概念。

如果你已有 1 年以上机器学习经验，这门课依然有帮助，但它主要为初学者设计。

### 先修要求是什么？

1. 3-6 个月 Python 编程经验。
2. 至少学过一门入门机器学习课程（也可能跳过，课程中有补充资源）。
3. 用过 Jupyter Notebooks 或 Google Colab（不会也可边学边上手）。
4. 愿意持续学习（最重要）。

针对前两项，我推荐 [Zero to Mastery Data Science and Machine Learning Bootcamp](https://dbourke.link/ZTMMLcourse)。它会系统讲清 Python 与机器学习基础（是的，我有点“偏心”，因为我也是授课老师之一）。

### 课程是怎么教的？

所有课程内容都可在 [learnpytorch.io](https://learnpytorch.io) 免费阅读。如果你偏好文字学习，建议直接按在线书学习。

如果你偏好视频，课程采用“学徒式”教学：我写 PyTorch 代码，你也跟着写。

课程口号是 *if in doubt, run the code* 和 *experiment, experiment, experiment!*，背后原因很简单：实践是最高效的学习方式。

我的核心目标只有一个：让你通过写 PyTorch 代码学会机器学习。

课程代码主要在 [Google Colab Notebooks](https://colab.research.google.com) 编写（你也可以用 Jupyter Notebooks），这是非常好用的免费实验环境。

### 学完整门课我会得到什么？

看完视频会有证书之类的内容。

但证书本身不是重点。

你可以把这门课看成“机器学习动量构建器”。

学完后，你会写下数百行 PyTorch 代码。

并接触到机器学习中很多关键概念。

这样当你做自己的机器学习项目，或阅读开源 PyTorch 项目时，会更有熟悉感；即便不熟，也知道该去哪里查。

### 课程中我会做哪些项目？

我们会从 PyTorch 与机器学习最基础的内容开始，即便你是新手也能跟上。

随后进入更进阶主题：神经网络分类、完整工作流、计算机视觉、自定义数据集、实验追踪、模型部署，以及我个人最喜欢的迁移学习。

过程中你会围绕总项目 FoodVision（一个食物图像分类模型）完成三个里程碑项目。

这些项目既能帮你练习关键 ML 概念，也能形成可展示给面试官的作品集。

### 这门课应该怎么学？

<img src="https://raw.githubusercontent.com/mrdbourke/pytorch-deep-learning/main/images/docs-how-to-approach-this-course-no-header.png" width=900 alt="how to approach this course: 1. code along, 2. explore and experiment, 3. visualize what you don't understand, 4. ask questions, 5. do the exercises, 6. share your work"/>

如前所述，视频版是学徒式教学。

也就是我写，你也写。

我建议你这样学：

1. **边学边敲（*if in doubt, run the code*）**：尽量自己把代码写出来，直到你对常见 PyTorch 写法形成肌肉记忆。
2. **主动探索（*experiment, experiment, experiment!*）**：机器学习高度实验驱动，想尝试自己的点子就去做。
3. **多做可视化（*visualize, visualize, visualize!*）**：纯数字容易抽象，把输入输出画出来会更容易理解。
4. **及时提问**：卡住时先搜索，找不到答案就去 [GitHub Discussions](https://github.com/mrdbourke/pytorch-deep-learning/discussions) 发帖。
5. **认真做练习**：每章都有练习区，自己做会卡住很正常，这正是学习新内容的过程。
6. **分享作品**：学到或做出有意思的内容就分享出来，既能训练表达，也可能收到他人的反馈帮助。

### 必须按顺序学吗？

章节内容是递进设计，但你也可以按兴趣跳读。

### 我该如何开始？

你可以在任意设备阅读内容，但最推荐在桌面浏览器中边看边写代码。

课程使用免费工具 Google Colab。如果你还没用过，建议先看 [Google Colab 入门教程](https://colab.research.google.com/notebooks/basic_features_overview.ipynb) 再回来继续。

开始步骤：

1. 点击任意章节链接，例如 "[00. PyTorch Fundamentals](https://www.learnpytorch.io/00_pytorch_fundamentals/)"。
2. 点击页面顶部 "Open in Colab" 按钮。
3. 连按几次 SHIFT+Enter，观察代码执行结果。

祝你学得开心，玩得尽兴。
